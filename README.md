# Google Pay Web Clone

## Project Description
A high-fidelity desktop web dashboard clone of Google Pay. This is a frontend-only visual implementation designed to replicate the mobile UI adapted into a professional desktop layout. It includes all the visual identity, content, sections, icons, colors, and hierarchy of the original app without any backend functionality.

## Tech Stack
- HTML5 (Semantic Structure)
- CSS3 (Vanilla CSS with CSS Variables for Material 3-inspired design tokens)
- JavaScript (Vanilla DOM interaction for basic navigation and carousels)

## Setup Instructions
Since this is a static frontend project with no external dependencies, running the project is incredibly simple:

1. Locate the index.html file in the root directory.
2. Open index.html directly in any modern web browser (e.g., Chrome, Edge, Safari).
   - Alternatively, you can drag and drop the index.html file into an open browser window.
3. No build tools, Node.js, or local servers are required to view the UI.
